# HomeoAssist for Android

Downloads of the HomeoAssist Android app. The clinic's dashboard is at
https://homeo-assist-f2c1b.web.app — its **Get the Android app** page always links the newest version here.

## Install
1. On the Android phone, open the newest release under **Releases** (right side) and tap the `.apk` file.
2. If Android asks, allow your browser to **install unknown apps** (Settings → Apps → Chrome → Install unknown apps).
3. Tap **Install**, then **Open**. In the app, open **Patients** and tap **Continue with Google** (or sign in with email).
4. If it says *No access yet*, ask a clinic admin to add your email under **Members** on the dashboard.

Updates: the app tells you when a newer version is out. Install it over the old one; your data stays.
Each release lists the file's SHA-256 so you can check the download.

This repository contains release files only — no patient data, which lives in the clinic's
Firebase project and is readable only by verified clinic members.
